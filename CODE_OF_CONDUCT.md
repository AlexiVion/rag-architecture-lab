# Community code of conduct

We want the RAG Architecture Lab to remain a constructive environment for open technical research.

Participants are expected to discuss evidence and technical disagreements respectfully, be clear about uncertainty, welcome constructive review, and credit collaborators and dataset authors. Harassment, threats, discrimination, personal attacks, and the publication of private information are not acceptable.

Project maintainers may edit or remove abusive contributions, limit participation, or close discussions that violate these expectations. Raise concerns privately with the repository maintainer; do not post personal information in public issues.

These expectations apply to repository issues, pull requests, reviews and discussions associated with the project.
